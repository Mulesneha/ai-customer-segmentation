# 🛒 AI Customer Segmentation

An interactive Machine Learning application that segments customers using **RFM Analysis** and **K-Means Clustering**.
Live Link:https://ai-customer-segmentation-34mfuhvssyv7pqry6qexfj.streamlit.app/
## 🚀 Features

- Customer transaction analysis
- RFM Analysis
- Recency calculation
- Purchase frequency analysis
- Monetary value analysis
- K-Means clustering
- Customer segment visualization
- 2D customer segmentation
- 3D customer segmentation
- Business insights
- CSV export

## 🧠 Machine Learning

The project uses:

- RFM Analysis
- StandardScaler
- Log transformation
- K-Means Clustering
- Plotly visualization

## 📊 RFM

### Recency

How recently the customer purchased.

### Frequency

How often the customer purchased.

### Monetary

How much money the customer spent.
